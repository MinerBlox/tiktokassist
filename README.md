# TikTok Assist

A lightweight two-screen frontend for attaching reusable text to TikTok videos.

- **Find text:** paste any saved TikTok video or photo URL and copy its assigned message.
- **Admin:** create, search, edit, and delete messages, with multiple TikTok links per message.
- TikTok tracking parameters are ignored when matching links.
- Data is stored in the browser with `localStorage`.

Open `index.html` or publish the repository with GitHub Pages.
